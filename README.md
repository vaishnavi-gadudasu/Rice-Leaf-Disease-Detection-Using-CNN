# Rice Leaf Disease Detection Using CNN

## Overview

Rice Leaf Disease Detection Using CNN is a deep learning-based image classification system that automatically detects and classifies diseases in rice leaf images using Convolutional Neural Networks (CNN). The project aims to support early disease identification and improve crop health management through automated image analysis.

## Objective

To develop an automated image classification system that accurately identifies rice leaf diseases using Convolutional Neural Networks (CNN), enabling early disease detection and reducing reliance on manual inspection.

## Diseases Detected

- Bacterial Leaf Blight
- Brown Spot
- Leaf Smut

## Methodology

1. Collect and preprocess rice leaf images.
2. Train a Convolutional Neural Network (CNN) model.
3. Classify rice leaf diseases.
4. Evaluate the model's performance.
5. Predict diseases from new rice leaf images.
